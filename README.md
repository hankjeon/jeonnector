# 전연결기 (jeonnector)

**전연결기(jeonnector)**는 연결기(Connector)의 물리적 핀 배치와 각 핀에 할당된 신호(Signal)를 시각적으로 확인하고 편집하는 핀맵(Pinmap) 설계·조회 프로그램입니다. 현재는 요구사항과 화면 설계를 정리하는 단계이며, 아래 기능은 구현 예정입니다.

신호의 물리적 특성(전원, 접지, 고속 신호 등 카테고리)에 따른 색상 구분을 통해 핀 배치의 적절성을 직관적으로 파악할 수 있도록 돕습니다.

## 주요 특징

- **물리적 핀맵 시각화**: 연결기의 실제 물리적 핀 배열을 2D 캔버스에 표시하고, CAD 스타일의 자유로운 확대/축소(Zoom) 및 화면 이동(Pan)을 지원합니다.
- **신호 색상 표시**: 신호별 개별 색상을 우선 적용하고, 없으면 카테고리 색상을 사용해 인접 핀 간 배치 상태를 확인합니다.
- **핀맵 뷰와 신호 목록 표의 양방향 연동**: 그래픽 핀맵 뷰와 표(Table) 형태의 신호 목록을 나란히 배치하여, 어느 한쪽에서 핀/신호를 선택하든 양쪽 화면에서 동시에 하이라이트됩니다.
- **신호 생성과 핀 할당**: 신호는 연결기별 신호표에서 생성하고, 핀맵에서는 해당 연결기의 기존 신호를 선택해 할당합니다.
- **연결기 부품 관리**: 자체 부품 데이터베이스와 별도 편집 화면, 그리드·스냅 편집, 선택한 부품 가져오기·내보내기를 제공합니다. 부품 정의는 하나로 관리하고 프로젝트의 연결기별 설정에서 좌우 반전을 선택합니다.
