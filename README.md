# 전연결기 (jeonnector)

**전연결기(jeonnector)**는 연결기(Connector)의 물리적 핀 배치와 각 핀에 할당된 신호(Signal)를 시각적으로 확인하고 편집하는 핀맵(Pinmap) 설계·조회 프로그램입니다.

신호유형(전원, 접지, 고속신호 등)에 따른 색상 구분을 통해 핀 배치의 적절성을 직관적으로 파악할 수 있도록 돕습니다.

## 주요 특징

- **핀맵 시각화**: 연결기의 실제 핀 배열을 2D 캔버스에 표시하고, CAD 스타일의 확대·축소(Zoom) 및 화면 이동(Pan)을 지원합니다. 확대·축소 시에도 핀과 외곽선의 선 굵기는 일정하게 유지됩니다.
- **신호 색상 및 주변 영역 표시**: 신호별 개별 색상을 우선 적용하고, 없으면 신호유형 색상을 사용합니다. 핀을 선택하면 선택한 핀의 외곽선을 굵게 표시하고, 동일 신호가 할당된 모든 핀의 주변 영역을 반투명 색상으로 표시합니다.
- **핀맵과 신호표의 양방향 연동**: 핀맵과 신호표를 나란히 배치하고 도킹·플로팅 및 크기 조정을 지원하며, 어느 한쪽에서 핀이나 신호를 선택하든 양쪽 화면에서 함께 연동됩니다.
- **신호 생성과 핀 할당**: 신호는 연결기별 신호표에서 생성하고, 핀맵에서는 우클릭 컨텍스트 메뉴로 기존 신호를 선택해 할당합니다. 신호유형은 프로젝트별로 관리합니다.
- **신호표 선작성과 번호 보존**: 부품 없이도 핀 번호를 작성·저장할 수 있습니다. 부품 선택·교체·핀 삭제 시에도 번호를 유지하고, 선택한 부품에 없는 번호는 주황색 경고로 표시합니다. 신호명은 `+5V`, `DATA+`, `RESET#`, `RD/WR` 같은 표기를 지원합니다.
- **마크다운 신호표 교환**: 파일 하나 또는 폴더의 연결기별 신호표를 미리보기 후 가져옵니다. 선택·전체 연결기 내보내기와 작성용 템플릿 만들기는 `파일 → 내보내기 → 마크다운`에서 사용합니다. 가져오기는 식별자와 신호표만 읽고 원본 문서를 수정하지 않습니다.
- **새 신호 입력**: 신호표 마지막 행에서 핀 번호부터 자유롭게 입력한 뒤 `추가` 또는 `Ctrl+Enter`로 확정합니다. 기존 신호 선택 시 속성을 가져오며, `초기화`로 입력 중인 값만 비울 수 있습니다. 할당·해제 후에는 현재 기준으로 즉시 재정렬합니다.
- **좁은 핀맵 구성**: 상단 조작부를 세 줄로 배치해 핀맵을 좁히고 신호표에 더 많은 공간을 배분할 수 있습니다.
- **연결기 부품 데이터베이스 및 편집기**: 기본 제공 연결기 27종(D-SUB SD 5종, D-SUB HD 5종, D38999 Series IV 8종, Micro-D MDM 9종)을 포함한 자체 부품 데이터베이스와 CAD 스타일 연결기 부품 편집기(그리드·스냅, 바둑판·원형 자동 배치, 외곽 그리기, 선택 부품 가져오기·내보내기, 기본 부품 복원)를 제공합니다.
