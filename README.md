# jeonnector

**jeonnector**는 연결기(Connector)의 물리적 핀 배치와 각 핀에 할당된 신호(Signal)를 시각적으로 확인하고 편집하는 핀맵(Pinmap) 설계·조회 프로그램입니다.

신호의 물리적 특성(전원, 접지, 고속 신호 등 카테고리)에 따른 색상 구분을 통해 핀 배치의 적절성을 직관적으로 파악할 수 있도록 돕습니다.

## 주요 특징

- **물리적 핀맵 시각화**: 연결기의 실제 물리적 핀 배열을 2D 캔버스에 표시하고, CAD 스타일의 자유로운 확대/축소(Zoom) 및 화면 이동(Pan)을 지원합니다.
- **신호 카테고리별 색상 표시**: 신호의 특성에 맞춘 색상 구분으로 인접 핀 간 배치 상태를 한눈에 확인할 수 있습니다.
- **핀맵 뷰와 신호 목록 표의 양방향 연동**: 그래픽 핀맵 뷰와 표(Table) 형태의 신호 목록을 나란히 배치하여, 어느 한쪽에서 핀/신호를 선택하든 양쪽 화면에서 동시에 하이라이트됩니다.
- **양방향 편집**: 핀맵 캔버스와 신호 목록 표 양쪽에서 신호를 할당하거나 수정할 수 있습니다.
